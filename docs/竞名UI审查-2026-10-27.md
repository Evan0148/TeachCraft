## 三、明确延后（附原因）

| 项 | 原因 |
| :--- | :--- |
| 名单虚拟化（ItemsControl → 虚拟化 ListBox） | 一个班通常 ≤60 行，实测滚动未见掉帧；改造会引入虚拟化下的焦点/编辑态问题，收益不足 |
| 表格内键盘导航（方向键/Delete 删行/Enter 提交） | 需要自定义 `KeyboardNavigation` 与单元格焦点模型，属一次独立交互改造，已在备份方案中登记 |
| 导入进度条与取消 | 单班导入 <1s；已用 `IsBusy` 禁用表格与按钮防重入，进度粒度收益低 |
| 弹窗关闭后焦点回到来源格 | Avalonia 无内置焦点恢复机制，需要记录并 `Focus()` 回填；当前关闭后焦点落在窗口，属可接受 |
| 高亮摘要在顶栏与左栏重复 | 两处位置服务不同场景（看板 vs 筛选器），重复但无害 |
