# 03 · 功能与工具面板

| :--- | :--- | :--- | :--- | :--- |
| 01 | `image-convert` | 图片格式转换 | 目标格式 PNG/JPG/WebP、画质 | `*-转换.<format>` |
| 02 | `image-resize` | 图片尺寸调整 | 宽、高、百分比、等比 | `*-缩放.<ext>` |
| 03 | `image-compress` | 图片压缩 | 画质 40–100、最大边长 | `*-压缩.<ext>` |

## 实现要点

- **图片解码**：`SKCodec` + 强制 BGRA；按 EXIF `EncodedOrigin` 摆正手机照片。
- **JPG 输出**：先铺白底再绘制，避免透明背景变黑。
- **水印**：按图像平均亮度自动选白字或墨字；始终加一层反色阴影保证可读。
- **压缩**：PNG 无损，画质滑块不改变 PNG 质量，体积收益主要靠缩小边长；界面结果文案会明确说明。
- **PDF 合并/拆分**：PdfSharpCore 导入页对象，禁止输出路径覆盖任一输入。
- **PDF 转图片**：PDFtoImage（PDFium）渲染，逐页写 PNG，`Progress<int>` 汇报。
- **PDF 转 Word 文字模式**：PdfPig `ContentOrderTextExtractor` 提取，OpenXML 逐行建段；分页保留。
- **PDF 转 Word 版面模式**：每页按 DPI 渲染成 PNG，按 A4 内容区缩放后嵌入 DOCX；视觉保真但不可编辑。
- **Word 转 PDF**：OpenXML 读取段落/表格 → QuestPDF A4 排版；标题、加粗、斜体、下划线、居右/居中、表格边框保留；页脚页码。
- **图片合成 PDF**：QuestPDF 每页一张图，A4 根据横竖自动切换，`FitArea` 居中。

## 分晓入口

- 「案头常备」卡片与侧栏「分晓 · 成绩条」都打开右侧详情抽屉。
- 详情内展示两张真实截图、平台/输入/输出/数据说明、三条功能摘要。
- 「打开应用」→ 同进程创建分晓主窗口；不是启动外部 exe。

## 面板状态机

1. 未选文件：投放区 + 选项 + 禁用「开始处理」。
2. 已选文件：显示文件名 / 多文件有序列表；「清空」可用。
3. 处理中：禁用按钮，显示进度条与百分比（长任务）。
4. 成功：结果摘要 +「打开所在文件夹 →」。
5. 失败：结果文字变陶土色，状态栏圆点同步变红；按钮恢复可用，方便重试。

## 交互补充

- 拖拽：抽屉打开时，整个窗口接受文件投放；单文件工具取第一个，多文件工具追加并去重。
- 搜索：按名称、ID、描述、输入/输出格式匹配；无结果时隐藏空分类并显示空状态。
- 多文件顺序：每行 `↑ ↓ ×`，序号实时重排。
- 键盘：`Ctrl/Cmd + K` 聚焦搜索，`Esc` 关闭抽屉或清空搜索。
- 无障碍：工具卡、侧栏导航、投放区、开始处理按钮均设置了 `AutomationProperties.Name`。

## 已知边界

- Word 转 PDF 不渲染 DOCX 内嵌图片、页眉页脚、分栏、浮动对象。
- PDF 转 Word 文字模式会丢失复杂版面；需要版式时选「保留版面」。
- PDF 转图片输出到文件夹，不自动打 zip（桌面场景更自然）。
- 加密 PDF 会提示先解除密码，不做破解。
- `linux-arm` 不支持（QuestPDF 原生库缺失）。
