## 实现要点

- **图片解码**：`SKCodec` + 强制 BGRA；按 EXIF `EncodedOrigin` 摆正手机照片。
- **JPG 输出**：先铺白底再绘制，避免透明背景变黑。
- **水印**：按图像平均亮度自动选白字或墨字；始终加一层反色阴影保证可读。
- **压缩**：PNG 无损，画质滑块不改变 PNG 质量，体积收益主要靠缩小边长；界面结果文案会明确说明。
- **PDF 合并/拆分**：PDFsharp 导入页对象，禁止输出路径覆盖任一输入。
- **PDF 转图片**：PDFtoImage（PDFium）渲染，逐页写 PNG，`Progress<int>` 汇报。
- **PDF 转 Word 文字模式**：PdfPig `ContentOrderTextExtractor` 提取，OpenXML 逐行建段；分页保留。
- **PDF 转 Word 版面模式**：每页按 DPI 渲染成 PNG，按 A4 内容区缩放后嵌入 DOCX；视觉保真但不可编辑。
- **Word 转 PDF**：OpenXML 读取段落/表格 → QuestPDF A4 排版；标题、加粗、斜体、下划线、居右/居中、表格边框保留；页脚页码。
- **图片合成 PDF**：QuestPDF 每页一张图，A4 根据横竖自动切换，`FitArea` 居中。

## 分晓入口

- 「案头常备」卡片与侧栏「分晓 · 成绩条」都打开右侧详情抽屉。
- 详情内展示两张真实截图、平台/输入/输出/数据说明、三条功能摘要。
- 「打开应用」→ 同进程创建分晓主窗口；不是启动外部 exe。
- 分晓有两条导入通道：
  - 「选择成绩总表」只接受能生成成绩条的学生成绩数据（全科汇总、单科成绩报告、学生小题明细）；
  - 「导入分析报表…」接受智学网导出的统计对比、学业等级/分段、临界生、优秀生学困生、缺考、需关注、试卷分析等文件，解析后显示在数据概览底部的「分析报表」区块（报表 chip + 工作表切换 + 只读表格）。
- 分析报表不需要先导入成绩总表：没有任何考试会话时报表存在独立区，概览页只显示「分析报表」区块，拖入即看；之后导入成绩总表会自动并进新会话。走错入口（用「选择成绩表」选到报表）也会自动按报表导入，不再拒绝；客观题填涂表（准考证号/姓名/科目/客观分/题号列）由导入器在结构层拒绝，题号列不会被当成科目读出假成绩会话。zip 会提示先解压。
- 导入 / 解析 / 导出期间盖一层忙碌遮罩：`#66141413` 暗幕 + 纸色卡片（0.22s 放大淡入）+ 陶土弧线匀速旋转（0.9s / linear），主文案跟随 `BusyText`，多文件拖入时显示 `2/3`；不忙时动画类被摘掉，不空转 CPU。样式 `Border.busy-in` / `Canvas.busy-spin` 同步在 `src/TeachCraft.App/App.axaml`。
- 拖拽与启动参数自动分流：成绩表建立/新增考试会话，分析报表挂到当前会话；混拖时先处理成绩表；只拖报表且无会话时提示先拖成绩总表。
- 混合工作簿（一个文件既有成绩数据又有报表页）两条通道同时产出：导入成绩后自动挂载文件内报表，状态栏提示「含 N 份分析报表」。
- 多班级报表在标题右侧提供班级下拉：单班成绩表导入全年级报表时自动默认定位到该班（「九A1」≈「九年级A1」），否则「全年级」；行式报表裁行、列式报表保留公共列与所选班级列；无班级维度时隐藏。

## 归位 · SeatGrid（常备应用）

- 侧栏「归位 · 座位表」与案头常备卡均可打开，同进程独立窗口，单实例复用。
- 名单：xlsx / xls / csv；自动识别姓名、性别、学号、身高、视力、成绩、原小组、备注；带表头与无表头都支持。
- 排座：4 组 × 6 排 × 2 列等任意布局；名单顺序 / 男女交替 / 随机 / 按身高 / 按视力；手动点座位 + 左侧选学生放入。
- 设置：教师/学生视角、组/排/列、格子大小、标题与信息、9 种配色、讲台间距、字号、加粗、隐藏空座位、标记女生、两字姓名加空格、组排提示、重置样式。
- 导出：打印 PDF、PNG 图片、Excel 座位表（含名单页）、配置 xlsx 导入/导出、窗口内预览。
- 详细实现与边界见 `.memory/09-归位座位表.md`。

## 时序 · ClassBlock（常备应用）

- 侧栏「时序 · 课程表」与案头常备卡均可打开，同进程独立窗口，单实例复用。
- 总表：仅 `.xlsx`；自动识别年级、学期、月份、课程表工作表与全部班级，并读取班主任、午学、课服 / 晚修、早读。
- 班级：左侧列表（搜索班级名 / `九6` / 班主任），选中即生成；默认选中第一个班。
- 课表：固定 16 行——早读、1–7 节、大课间、午餐、午学、课服1/2、晚餐、新闻联播、晚修；午餐 / 晚餐整行红字，大课间与新闻联播合并星期列，晚修为两段时间的高行。
- 设置：标题、显示任课教师、显示早读 / 午学 / 课服 / 晚修；改动立即重排。
- 导出：打印 PDF（A4，位图嵌入）、PNG 图片；界面中显示的即为同一张图。
- 详细实现与边界见 `.memory/10-时序课程表.md`。

## 织序 · GradeWeave（常备应用）

- 侧栏「织序 · 课表编排」与案头常备卡均可打开，同进程独立窗口，单实例复用。
- 定位：时序的上游。时序把已有总表排版打印，织序先把全年级总表排出来。
- 五步流程：01 确认作息时间表 → 02 教研 → 03 分层走班 → 04 领导会议 → 05 正式编排；作息未确认时生成按钮禁用。
- 自动保存：每 2 秒检查工程改动，当前 `.weave.json` 原子写回；无路径或写入失败时保存到本机恢复文件，底部状态栏显示保存时间，空状态可恢复上次自动保存。
- 作息：一天的正课 / 早读 / 课间 / 午餐 / 课服 / 晚修等时段可编辑；内置七 / 八 / 九年级预设，确认后编译为节次，改动即失效。
- 导入：年级工作簿 `.xlsx`（分工表 / 确认表 / 课程表 / 会议活动备注），自动提取班级、学科、教师、任课关系与周课时；`.xls` 提示另存为。
- 约束：教研按学科锁定，会议按岗位 / 指定教师锁定（可放课后服务 / 晚修扩展时段），分层走班按 A/B 层同步占用；走班组教师下拉只列当前学科任课教师，选中教师自动带入其任课班教室；先定约束再排普通课。
- 编排：每班教学时段视为排列，分散式初始分配 + 最小冲突局部搜索；超时降级并列出未排课程，不谎报排完。同一班级同一学科每天 ≤ 2 节、下午 ≤ 1 节，主课优先上午。20 班 / 62 教师 / 694 节的真实规模回归可排满。
- 冲突：教师冲突、班级冲突、教师不可用（教研 / 会议）、走班冲突、缺任课教师、课时不符、未排课程，共七类，均带星期与节次。
- 导出：总表、分工表、班级课表、教师课表、冲突页的 Excel；PNG；班级 / 教师打印 PDF。
- 首版边界：单年级、五天；正课节次由已确认作息决定（默认 7 节）；课服 / 晚修只作为扩展时段，不参与正课自动编排；暂不导入 B 层学生名单。
- 详细实现与边界见 `.memory/12-织序课表编排.md`。

## 面板状态机

1. 未选文件：投放区 + 选项 + 禁用「开始处理」。
2. 已选文件：显示文件名 / 多文件有序列表；「清空」可用。
3. 处理中：禁用按钮，显示进度条与百分比（长任务）。
4. 成功：结果摘要 +「打开所在文件夹 →」。
5. 失败：结果文字变陶土色，状态栏圆点同步变红；按钮恢复可用，方便重试。

## 交互补充

- 拖拽：抽屉打开时，整个窗口接受文件投放；单文件工具取第一个，多文件工具追加并去重。
- 搜索：按名称、ID、描述、输入/输出格式匹配；无结果时隐藏空分类并显示空状态。
- 多文件顺序：每行 `↑ ↓ ×`，序号实时重排。
- 键盘：`Ctrl/Cmd + K` 聚焦搜索，`Esc` 关闭抽屉或清空搜索。
- 无障碍：工具卡、侧栏导航、投放区、开始处理按钮均设置了 `AutomationProperties.Name`。

## 已知边界

- Word 转 PDF 不渲染 DOCX 内嵌图片、页眉页脚、分栏、浮动对象。
- PDF 转 Word 文字模式会丢失复杂版面；需要版式时选「保留版面」。
- PDF 转图片输出到文件夹，不自动打 zip（桌面场景更自然）。
- 加密 PDF 会提示先解除密码，不做破解。
- `linux-arm` 不支持（QuestPDF 原生库缺失）。
