# 04 · 界面设计系统

设计语言直接继承「分晓 · GradeStrip」：Anthropic 的纸墨感、衬线标题、等宽编号、细边白卡、陶土色点缀。

## 色板

| 语义 | 色值 | 用途 |
| :--- | :--- | :--- |
| Ink | `#141413` | 主文字、主按钮、标题 |
| InkSoft | `#3D3B36` | 正文 |
| Muted | `#6F6A5E` | 辅助文字、标签（on Paper 5.11:1） |
| Paper | `#FAF9F5` | 窗口底色 |
| PaperDeep | `#F4F2EC` | 提示块、轨道 |
| Card | `#FFFFFF` | 卡片 |
| Line | `#E7E3D8` | 1px 描边 / 分隔线 |
| Accent | `#D97757` | 陶土色点缀、进度、强调 |
| AccentDeep | `#A34A36` | 链接、错误、编号（on Paper 5.55:1，小字达 AA） |
| Moss | `#5A7A4B` | 成功状态 |
| Tier1–5 | `#70AD47` `#C6E0B4` `#DDEBF7` `#FFF2CC` `#F8CBAD` | 成绩条 / 迷你预览 |

Fluent 控件强调色统一覆盖为 `SystemAccentColor = #D97757`，避免默认蓝色滑杆破坏配色。

## 字体

| 角色 | 字体 |
| :--- | :--- |
| 衬线标题 | `Anthropic Serif` → SimSun / Songti SC |
| 正文 / 控件 | Microsoft YaHei UI / Microsoft YaHei |
| 编号 / 工具 ID / 小标签 | `Anthropic Mono` |

字体以 `AvaloniaResource` 打包，URI 形如 `avares://TeachCraft/Assets/Fonts#Anthropic Serif`。
**改 `AssemblyName` 会改变 avares URI，必须同步 App.axaml 与 ProjectPanelView。**

## 尺寸与布局

- 窗口 1200×840，最小 1120×720；侧栏固定 232；内容最大宽 1104。
- 课堂工具窗（归位 / 时序 / 织序）1440×920，最小 1120×680；所有窗口打开时由 `src/Shared/WindowFit.Clamp` 钳进当前屏幕工作区（按 `Screen.Scaling` 在 DIP 与物理像素间换算，最小尺寸会先让路）。
- 卡片圆角 10（工具）/ 12（常备）；按钮与输入 6–8；抽屉宽 452。
- 工具卡双列，`UniformGrid Columns=2`，卡内 44px 字形方块 + 编号/ID + 名称 + 描述。
- 常备卡：左文右图（372px 成绩条叠纸预览），左侧 2px 陶土色书脊。

## 组件与样式

- `Button.tool-card`：自定义模板（无 Fluent 默认底色），悬停描边加深、底色转暖白，字形块转陶土。
- `Button.nav`：文字式导航，选中底色 `#F1EEE5` + 左侧 2px 陶土条。
- `Button.dropzone`：透明模板 + `Rectangle` 虚线框（`StrokeDashArray 5,4`）。
- `Button.panel-close` / `Button.mini`：小尺寸轻量按钮。
- `Border.card` / `Border.chip` / `Border.panel`：细边、无阴影。
- 状态栏：左侧状态圆点 + 文案（超长省略 + ToolTip），右侧 `V1.0.0 · 10 TOOLS`。

## 动效

| 场景 | 时长 / 曲线 |
| :--- | :--- |
| 卡片悬停 | 160ms，背景 / 描边颜色过渡 |
| 按压 | 80ms `CircularEaseOut`，`scale(0.97)` |
| 抽屉推入 | 320ms `CubicEaseOut`，X 452→0 + 透明度 0→1 |
| 抽屉退出 | 240ms `CubicEaseIn` |
| 遮罩 | 260ms 淡入 / 200ms 淡出 |
| 页面切换 | 160–200ms 淡入 |

## 与 HTML 视觉稿的差异

- HTML 稿（`design-preview/`）是评审基准；C# 版按桌面窗口实际尺寸重排，未保留右侧竖排边注。
- 原生文件/文件夹选择器取代了 Web 的拖放上传，抽屉仍是同一套版式。
- 工具编号从 HTML 的 09–18 调整为 01–10（因为只收录图中这 10 件），工具 ID 原样保留。
- 增加文件选择后的有序列表、结果「打开所在文件夹」、真实进度与错误色。

## 应用图标

- 知微主图标为纸色圆角方块 + 墨色条块 + 陶土竖线；侧栏、卡片与窗口标题统一使用这一几何网格语言。
- 分晓、归位、时序各有独立图标（成绩条 / 座位网格 / 课程表），侧栏与常备卡使用内联 `Canvas` 版本，缩放不失真。
- 可执行文件与安装包图标在 `src/TeachCraft.App/Assets`、`src/SeatGrid.App/Assets`、`src/ClassBlock.App/Assets`；设计稿与备选方案在 `design/logo/` 下。
- 窗口 `Icon` 统一使用 `avares://TeachCraft/Assets/...` 绝对资源路径，避免相对路径在不同入口下解析失败。

## 无障碍

- 所有工具卡暴露名称；侧栏四项导航设置 `AutomationProperties.Name`；投放区、开始处理按钮同样有名称。
- 辅助文字统一 `MutedBrush = #6F6A5E`（on Paper 5.11:1），错误文字用 `AccentDeepBrush = #A34A36`（5.55:1）；不再使用 `#9C9585 / #A29C8C / #8E8776 / #B0AA9C` 等散值。
- 动效克制，不使用弹跳或大幅位移。
