# 12 · 织序课表编排（GradeWeave）

## 定位

织序是知微的第四件常备应用：把「分工表 + 确认表 + 课程表 + 会议活动备注」组成的年级工作簿，编排成一份没有教师、班级、教研、走班、会议冲突的全年级课表。它是时序（单班课表展示）的上游——时序负责把已有总表排版打印，织序负责先把总表排出来。

- 作用域：单个年级、单个学期，五天 × 作息正课节次（默认 7 节，可追加课服 / 晚修等扩展时段）。
- 原则：本地优先、不上传；导入与导出不覆盖源文件；示例一律使用合成数据。
- 首版窗口：`src/GradeWeave.App/GradeWeaveWindow.axaml`；Core：`src/GradeWeave.Core`。

## 五步流程

- 数据入口有三个：
  1. **导入工作簿**：`.xlsx` / `.xls`。`.xls` 由 NPOI 读取（含合并区域），转内存工作簿后与 `.xlsx` 走同一解析管线；其他格式提示另存，不静默转换。
  2. **打开工程**：`.weave.json`。
  3. **全新制作**：空状态或顶栏「全新制作」→ `NewProjectWindow` 配置学校 / 年级 / 学期 / 班级数 / 学科课时（默认九年级九科，可增删改，主课优先上午），班级名按年级自动生成（九年级 → 九（1）班…）→ 05 步「编排对象」卡内「教师分工」打开 `AssignmentEditorWindow`，按「班级 × 学科」表格填班主任与任课教师，教师按姓名自动建档（清空格子即取消任课），支持加班 / 删末班 / 改班名。
- **01 作息时间（前置门槛）**：确认一天的正课节次、课间、早读、午餐、课服 / 晚修等时段。未确认时顶栏「生成课表」与 05 步「重新生成」禁用，调度器也会抛中文异常。详见下文「作息时间表」。
- **核对**：检查班级、学科、教师、任课关系与周课时；缺教师、课时不符在这里先修，不带着问题排课。`教师分工` 不进顶栏，只作为编排流程的一环放在 05 步「编排对象」卡内（链接按钮 + 「N 条任课 · N 位教师」摘要），任课为 0 时提示先补分工；「全新制作」完成后直接接上分工窗口。
- **约束与编排**：确认教研（按学科）、会议（按岗位 / 指定教师）、分层走班时段后，`WeaveScheduler` 自动排普通课。
- **检查与导出**：`ConflictAnalyzer` 列出冲突与未排课程，确认后导出总表、分工表、班级课表、教师课表与冲突页。

## 数据结构

`GradeWeave.Core.Models`：

| 类型 | 作用 |
| :--- | :--- |
| `WeaveProject` | 一个年级一个学期的完整工程：学校、年级、学期、作息时间表、节次、班级 / 学科 / 教师 / 任课关系、约束、已排课与警告。 |
| `WeaveTimetable` | 一天的有序作息：`Name`、`Rows`、`ConfirmedSignature`；`IsConfirmed` 由当前内容签名与确认签名比较得出，改任意一行即失效。 |
| `TimetableRow` | 作息行：`Kind`、名称、起止时间。类型固定为 `Lesson / MorningReading / Break / NoonStudy / Lunch / Rest / EyeExercise / AfterSchool / EveningStudy / Routine`。 |
| `PeriodSlot` | 节次定义（序号、名称、时间、是否下午、是否扩展时段）。由已确认的作息编译；默认 7 节正课。 |
| `SchoolClass` | 班级（Id、名称、班主任）。 |
| `Subject` | 学科（周课时、是否主课、是否分层、颜色）。 |
| `Teacher` | 教师（学科、周课时、岗位、是否领导）。 |
| `TeachingAssignment` | 某班某学科的任课教师与周课时；分层走班带 `LayerName`。 |
| `ResearchBlock` | 教研：某学科全部任课教师在指定「星期 + 节次区间」不可排课。 |
| `MeetingBlock` | 会议：按岗位（`Roles`）、指定教师（`TeacherIds`）或全体教师锁定「星期 + 节次区间」。 |
| `LayeredClassGroup` | 分层走班：同组班级在固定时段（或自动安排的落位槽位）上同一学科，`Layers` 描述 A/B 层的教师与教室；`IsFlexible` + `WeeklyHours` 为自动安排模式，`ResolvedSlots` 保存编排落位。 |
| `ActivityBlock` | 临时活动：名称、星期、起止时间、归属节次（0 = 自动匹配）、参与班级（空 = 全年级）、教师 / 地点、`Overlay` / `Replace`、备注。 |
| `LessonPlacement` | 一个班一天一节课的落点（学科、教师、层、组、是否固定、备注）。扩展时段与活动占位复用该结构；活动占位带 `IsActivity` / `ActivityId` / `ActivityName` / `ActivityTime`。 |
| `UnplacedLesson` | 排不下的课（班级、学科、教师、节数、原因）。 |

工程可另存为 `.weave.json`（`WeaveProjectIO`），便于备份与换机继续；JSON 使用宽松转义，中文可读。旧工程没有 `Timetable` 字段时，`WeaveProjectIO.Load` 按现有 `Periods` 还原一份未确认作息，老师确认后才允许重新生成。

## 作息时间表（01 步）

- **定位**：作息是一天的时段结构，不是五天课程表。它决定正课节次数、起止时间与课服 / 晚修等扩展时段，是生成课表的硬前置；确认动作本身就把作息编译进 `WeaveProject.Periods`。
- **数据与签名**：`WeaveTimetable.ConfirmedSignature` 保存确认时的内容签名（类型 + 名称 + 起止时间的 SHA-256）；`IsConfirmed` 每次比较当前签名，因此改任意一行、调换时间或删除时段都会立即失效，不需要额外的脏标记。
- **行类型**：`Lesson` 编译为正课（Index 1..N）；`AfterSchool / EveningStudy` 编译为 `IsExtension=true` 的扩展节次（排在正课之后）；`MorningReading / Break / NoonStudy / Lunch / Rest / EyeExercise / Routine` 只作作息说明，不进入编排。
- **校验**（`TimetableService.Validate`）：拒绝空表、没有正课、非法时间、结束早于开始、任意两段时间重叠、正课超过 15 节、扩展时段超过 8 个；行序与时间不一致只给「会按时间重排」提示。确认时再次校验，错误直接抛 `GradeWeaveException`。
- **确认与缩减**：`TimetableService.Confirm` 按时间排序、编译 `Periods`、写回签名；若正课节次减少，超出新正课范围的 `LessonPlacement` 会被移除并在状态栏 / 编辑窗口如实报告。教研、会议、固定走班、活动的越界引用只提示，不静默删改；活动原归属节次不存在时改为按时间自动匹配。
- **编辑窗口**（`TimetableEditorWindow`）：参考 ClassIsland 的时间表编排方式，做减法后的三栏结构——左侧时段列表（类型下拉 + 新增 / 上移 / 下移 / 复制 / 删除 / 按时间排序）、中间选中时段详情（类型 / 名称 / 起止时间）、右侧编译后的节次预览；顶部一条按真实时长等比绘制的横向时间轴，带整点刻度与 tooltip。编辑只改 `Clone()` 草稿，取消不污染工程；「确认并应用」才调用 `TimetableService.Confirm` 并关闭窗口返回结果。
- **内置预设**：`WeaveTimetables.Presets` 提供九年级、八年级、七年级标准作息与「仅正课七节」；七年级早读提前到 7:10—7:30；七 / 八年级按第四节错峰（七年级第四节 11:00—11:40、八年级 11:10—11:50）并顺延午餐。预设只用通用年级名，禁止写入任何真实学校作息。
- **编排门槛**：`WeaveScheduler.Generate` 首先检查 `TimetableService.IsConfirmed`，未确认直接抛「请先在「作息时间」里确认时间表，再生成课表。」；`LessonPlacementService.Place` 与界面的手动放课 / 拖拽 / 清除也先检查同一签名，未确认一律拒绝并提示回 01 步。顶栏「生成课表」、05 步「重新生成」均绑定 `CanGenerate`（未确认或忙时禁用），05 步「编排对象」卡还会显示未确认横幅与「去 01 步确认作息」入口。
- **界面网格**：年级网格、总表、教研网格、走班预览全部按 `Project.TeachingPeriodCount()` 动态生成行列，不再硬编码 7 节；会议下拉按实际节次生成，旧工程没有扩展时段时保留第 8–10 节兜底选项。

## 自动保存

- **触发**：窗口内 `DispatcherTimer` 每 2 秒检查一次工程；只有工程事件标记为脏或每 3 个心跳（约 6 秒）才序列化。序列化在 UI 线程取快照，写入在 `Task.Run` 后台完成；`IsBusy`（生成 / 导入）期间跳过，避免读到半改状态。关闭窗口时 `OnClosed` 同步补写一次。
- **落盘目标**：当前工程来自或已手动保存为 `.weave.json` 时，`WeaveProjectIO.SaveJson` 原子写回该文件（同目录临时文件 + 覆盖）；没有工程路径、或工程文件不可写时，写 `%LOCALAPPDATA%\TeachCraft\GradeWeave\autosave.weave.json` 与 `autosave.meta.json`。**绝不写导入的 `.xlsx` / `.xls`**。
- **恢复**：恢复文件元数据记录保存时间、年级、班级数、课时数、作息确认状态与原始路径（只在本机）；空状态显示「上次自动保存：MM-dd HH:mm · 年级 N 个班」与「恢复上次自动保存」按钮。恢复后按无工程路径会话继续自动保存。
- **状态**：底部状态栏显示「自动保存 · HH:mm:ss」（写恢复文件时带「（恢复）」），失败时显示红色「自动保存失败」与原因，不静默失败；不覆盖左侧主状态提示。
- **测试**：`AutosaveTests` 覆盖恢复文件 + 元数据、当前工程文件写入、工程路径不可写回退、原子覆盖、清理与损坏恢复文件；本机实际走查确认 `%LOCALAPPDATA%` 下生成 18KB 恢复文件与元数据。

## 编排算法策略

- **排列式建模**：每个班的「5 天 × 正课节次」个教学时段视为一个排列，先按「教师稀缺度 + 学科课时」做分散式初始分配；交换同一班的两节课不会破坏班级网格，因此不会出现「班级有空位但教师对不上」的残局。
- **约束优先**：教研、分层走班、会议作为固定占用先写入；走班的 A/B 层记录按「组 + 节次 + 层」只占一次教师时间，跨班合层上课不会被误判为教师冲突。
- **会议时段**：可选正课节次与作息里的课服 / 晚修扩展时段；扩展时段不参与正课编排，可用于全体教师大会、行政会等。这样不会因为把会议硬塞进正课节次而导致 20 个班排不满。
- **最小冲突局部搜索**：以教师冲突、教研/会议占用、同科每日超限为代价，随机挑选冲突格在同一班内交换；代价下降即接受，局部最优时做少量随机游走。
- **超时降级**：超过 `ScheduleOptions.TimeLimit`（默认 8 秒）即停止搜索，按「教师冲突 / 教研会议占用 / 同科上限」逐项移除冲突课，把结果写进 `ScheduleResult.Unplaced`；界面必须如实显示，不得报「全部排完」。
- **硬约束**：同一教师同一时段只能一节课；同一班级同一时段只能一节课；教研 / 会议锁定期间相关教师不可排课；走班的参与班与 A/B 层教师同步占用。
- **软约束**：同一班级同一学科每天 ≤ 2 节、下午 ≤ 1 节（`MaxSameSubjectPerDay` / `MaxSameSubjectPerAfternoon`）；主课优先上午（`PreferMainMorning`）。
- **规模基线**：20 个班、62 位教师、694 节正课、5 条教研块，约 0.5–0.7 秒排满且 0 冲突（`SchedulerScaleTests`）。如果全体教师大会占用正课节次，剩余可用时段少于课时总数，属于约束本身不可行；工具会如实报告未排课时，应在 04 步把会议挪到课后服务/晚修时段。

- **走班时段分两模式**（`LayeredClassGroup.IsFlexible`）：
  - **自动安排**（新建走班组默认）：不占固定时段，只设「每周走班课时」（1—7）。`PermutationScheduler.ResolveFlexibleGroup` 在固定教研 / 会议 / 固定走班组落位之后，按「参与班都空闲 + 各层教师都空闲 + 不撞教研会议 + 同科每日不超限」挑选槽位，落位写入 `ResolvedSlots`。除不在行政班上课外与常规课完全一样灵活。一个槽位都找不到时整组退化为普通课并在消息里说明；部分落位时余量按普通课编排，绝不静默丢安排。重新生成课表会重新挑位。生成后状态栏显示实际时段（如「星期二第 1 节、星期四第 5 节 · 2 个班同节走班」），班级格与总表格用底色与「走班 · N 个班同节」标记提示同组参与班都在上走班课，悬浮提示列出 A/B 层教师。`ConstraintRules.TryGetLayeredGroupAt` 同时识别固定区间与 `ResolvedSlots`，手动放课、拖拽、清除与格子预览都按同一判定。
  - **固定时段**：学校已排定时才选，自选星期 + 节次区间，生成前作为硬约束写死。
  - 参与班级多选支持「全选 / 清空」，班级数多时勾选区可滚动。
  - **分层教师**：每层教师下拉只列当前学科的任课教师（`WeaveProject.TeachersOfSubject`：分工表任课关系 + 教师档案学科别名匹配），切换学科会清掉不属于新学科的旧选中教师；保存时再次校验教师属于该学科，缺任课教师时提示先补 05 步分工。
  - **分层教室**：每层「教室」是下拉框，选项 = 上方勾选的参与班级（班级名即教室）。勾选变化或增删层时按 A、B…层序自动带入（只填空值，不覆盖已有选择）；教室带入后也会反查分工表，把该班该学科的任课教师自动带入；选中教师后则优先把教室带成该教师在本学科任课的参与班。旧工程手填且不在参与班里的值保留显示为附加项，保存时要求改选，不静默丢弃。

## 教师名单与分工五视角（05 步）

- **共享草稿**：`AssignmentEditorWindow` 的五个视角共享 `Rows` 草稿与 `TeacherRoster` 名单；切换视角只刷新派生集合，不重建草稿、不提前写回工程。点「保存分工」才调用 `Apply()` 同步教师档案、更新班级 / 班主任，按姓名重建 `TeachingAssignment` 并重算每位教师周课时。
- **教师名单（默认第 1 步）**：维护本年级教师姓名 + 学科；支持单条添加与「批量添加」（每行「姓名,学科」或只写姓名，学科无法识别记为未指定）。名单来源 = 工程已有教师 + 旧工程任课格里出现但没有档案的姓名。新增但未任课的教师也会写入 `Teacher` 档案（周课时 0）；删除前必须解除任课、班主任与课表 / 走班 / 会议 / 活动引用。名单为空时各班 / 学科下拉只有「未安排」，不会隐式建档。
- **班级视角**：一班一行，班主任 + 各学科教师；教师格为按学科过滤的名单下拉，空选项为「未安排」；保留添加 / 删除班级与 60 班上限。
- **教师视角**：左侧教师名录（搜索、去名单添加、班主任标记、任教班级数 / 周课时），右侧为该教师的「班级 × 学科」勾选矩阵。勾选即指派，再点取消；未勾选格显示其他教师姓名，便于直接替换；跨学科任课仍可在这里指派。
- **学科视角**：左侧学科列表（周课时、已填班数、教师数、待补标记），右侧逐班下拉选择本学科教师；「批量指定教师」下拉只列本学科教师，支持「填入空班 / 全部替换」，右栏列出本学科教师负载，可点「查看」跳到教师视角。
- **分工体检**：统计班级 / 学科 / 已填任课 / 待补格数与名单教师数；待补清单按班级 + 学科列出，可点「去填写」跳到学科视角；教师负载按周课时排序，标注未排课 / 跨学科 / 班主任，可点「查看」跳到教师视角。
- **下拉规则**：班级 / 学科格只列名单里同科目教师；旧工程里跨学科或未建档的当前值会临时保留在选项中，避免打开旧工程时显示成未安排。教师改学科后，下拉与体检统计立即刷新。
- **测试**：`AssignmentEditorTests`（草稿增删与 60 班上限）、`AssignmentEditorViewTests`（默认名单视角、单条 / 批量添加、按学科下拉、教师勾选、学科批量填入、未任课教师保存与删除、体检统计、跨视角跳转）。

## 手动放课（05 步）

- **入口**：班级视角或总表视角点击任意课程格，打开 `LessonEditorWindow`；列表按本班任课关系显示「学科 · 任课教师」，并附「应排 / 已排 / 余」课时与教师本节冲突预判。点一行即放入；有课时提示「替换 语文」；点「清空本格」可移除当前普通课。
- **候选来源**：`LessonPlacementService.GetCandidates` 先列本班 `TeachingAssignment`（含教师），再补未建任课关系的学科（显示「未设置任课教师」，放课后冲突检查会提示缺少教师）。候选顺序保持学科声明顺序，主课带陶土色标记。
- **写入规则**：`LessonPlacementService.Place` 把课写入 `LessonPlacement(IsFixed=true, Note="手动放课")`，重新生成课表时作为固定课保留，并从对应任课课时中扣除；目标格原有普通课被替换，活动占位与走班时段拒绝手动放课。教师冲突、教研 / 会议占用、超出周课时都只写警告并交给 `ConflictAnalyzer`，不静默改课。
- **交互保护**：走班课、活动占位不可拖拽 / 右键清除 / Delete 清除；需要调整时回到 03 步走班组或「活动」列表。手动放课后立即重绘课表并重新检查冲突。

## 锁课与冲突聚合台（05 步）

- **锁课**：课程格锁定即 `LessonPlacement.IsFixed=true`。`PermutationScheduler.PrepareFixedLessons` 每次生成先移除未锁定课，再以锁定课为硬约束重排剩余课时，因此锁定满意的课后再「重新生成」就是局部重排。单格入口：右键菜单「锁定本节 / 解除本节锁定」、选中后按 `L`；整班入口：表头「锁定本班 / 解锁本班」或右键菜单。拖拽移动 / 交换成功后自动锁定来源格与目标格，避免下次重排丢失手工调整。
- **排除范围**：活动占位（`IsActivity`）与走班时段（`IsLayered` 或 `ConstraintRules.TryGetLayeredGroupAt` 命中）不能锁定，提示回活动列表或 03 步走班组；作息未确认时拒绝锁课。
- **显示**：课程格左上角显示「锁」角标（活动、走班不显示）；悬浮提示追加「已锁定：重新生成时保留」；班级 / 教师 / 总表表头显示「锁定 N 节」，只统计普通课。
- **冲突聚合台**：`ConflictCenterWindow` 为非模态窗口，`ConflictCenterViewModel` 按 `ConflictKind` 固定顺序分组，支持类型 / 班级 / 教师 / 关键词筛选，显示「显示 N / 共 M 条 · 可定位 X · 位置未知 Y」。有节次条目点「定位」回到主窗口班级视角并选中课程格；无节次条目点「查看班级」定位到相关班级或教师，定位只读、不改课。主窗口课程变更且聚合台已打开时自动刷新。
- **测试**：`LessonLockTests`（单格锁定后重排保留、拒绝走班 / 活动、整班只锁普通课）；`ConflictCenterTests`（分组计数、类型 / 班级 / 教师 / 关键词筛选、空态）。

## 临时活动

- **入口**：05 步左侧「活动」卡片，点「+ 新增」打开 `ActivityEditorWindow`；点已有活动可编辑或删除。默认示例为「书法课 10:50—11:10」。
- **时间映射**：`ActivityResolver` 把 `StartTime/EndTime` 与各正课节的 `PeriodSlot.TimeText` 求重叠，端点相接不算重叠。`10:50—11:10` 落在九年级第 4 节（10:50—11:30）的开始段；跨两节会同时命中。时间完全落在课间或作息时间不标准时，必须手动指定 `Period`，否则拒绝保存。
- **叠加 `Overlay`（默认）**：不改课程、课时与冲突，只在界面格子里多一行「＋书法课」，Excel / PNG / PDF 多一行「书法课 10:50—11:10」。适合 20 分钟短活动、广播讲话。
- **替换 `Replace`**：`ActivityResolver.Apply()` 移除重叠节次原课，写入 `LessonPlacement(IsActivity=true, IsFixed=true)`。`PermutationScheduler` 每次开始前先 Apply，重排后活动仍占位。被移除课时会形成 `HourMismatch` / `Unplaced`，工具如实报告，不静默补课。
- **教师占用**：同一活动的多个班用 `ActivityId` 作为教师占用键，全年级同一活动不会被误报为教师冲突；活动允许不指定教师。
- **交互保护**：活动占位格禁止拖拽、右键与 Delete 清除；删除活动只释放占位，被替换的原课不会自动恢复，可重新生成课表尝试补回。
- **统计**：活动不计入教师「已排 / 应排」周课时，也不计入班级课表的「已排 / 应排」分子。

## 冲突类型

`ConflictKind` 固定为七类，`ConflictAnalyzer` 与调度器共用 `ConstraintRules` 判定，避免排课结果与冲突报告互相矛盾：

1. `TeacherClash` 教师同一时段被两个班占用。
2. `ClassClash` 同一班同一时段有两节课。
3. `TeacherUnavailable` 教师在教研或会议锁定期间被排课。
4. `LayeredClash` 走班组内班级或 A/B 层教师时段不同步。
5. `MissingTeacher` 任课关系缺少教师。
6. `HourMismatch` 实际节数与周课时不符（含走班已消耗课时）。
7. `Unplaced` 有课程未排入。

每条冲突尽量带 `DayIndex` / `Period`：能定位时界面与导出显示「星期 X 第 N 节」；导入数据缺节次时，冲突聚合台显示「位置未定位」并可定位到相关班级或教师。

## 导出结构

`GradeWeave.Core.Export`：

- `WeaveExcelExporter`：一个工作簿内分页——总表、分工表、班级课表、教师课表、冲突页；可由 `ExportOptions` 勾选或只导出单个班级 / 教师。
- `WeaveImageRenderer`：渲染 PNG，界面预览与导出共用同一份渲染结果，保证所见即所得。
- `WeavePdfExporter`：班级 / 教师课表 A4 打印 PDF，沿用「高分辨率 PNG 嵌入 A4」方案，避免中文字体内嵌导致体积膨胀。
- `WeaveConflictReportExporter`：单独导出冲突报告，便于发给年级组逐条核对。

导出路径不得覆盖已导入的工作簿；UI 层做 `IsSamePath` 检查。

## 边界（首版）

- 接受 `.xlsx` 与 `.xls`；其他格式提示另存，不静默转换。
- 只处理一个年级、五天；正课节次由已确认作息决定（默认 7 节，可增删）；课后服务与晚修可作为扩展时段，但不参与正课自动编排。
- 首版不提供「从零手工新建班级 / 教师 / 学科」的完整编辑器；数据入口是导入分工表或打开 `.weave.json` 工程。源数据有误时改工作簿后重导，或直接编辑工程 JSON。（2026-10-26 起已有「全新制作 + 教师分工」轻量入口，见五步流程第 1 条；学科课时仍在新建时配置。）
- 会议建议不自动应用：全体教师大会会锁住所有教师；若占用第 7 节，剩余时段可能少于总课时，属于约束不可行。工具会如实列出未排课程；老师可把会议改到作息里的课后服务 / 晚修扩展时段，或在 04 步改角色范围。
- 分层走班按 A/B 两层建模，暂不导入 B 层学生名单。
- 不支持跨年级联排、跨校调课、教师跨学科兼课的特殊权重。
- 冲突可定位到时段，但首版不做「一键自动改排」；需要在约束面板调整后重排。
- 打印 PDF 为位图嵌入，不做矢量课表。
