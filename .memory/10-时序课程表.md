# 10 · 时序 · ClassBlock

面向教师的课程表提取器：导入一份「教师安排总表」，自动识别年级、学期、月份与全部班级；选中目标班级后，生成一张可直接打印的课程表。

## 数据管线

```
MasterScheduleImporter.Import(path)
        │  (ClosedXML，仅 xlsx)
        ▼
MasterSchedule
   Info / Classes / HeadTeachers / LunchStudy / AfterSchool / EarlyReading / Warnings
        │
        ▼
TimetableBuilder.Build(master, "九6", template, settings)
        │  (template = 内置七/八/九预设或自定义模板；Slot 决定每行绑定的数据)
        │
        ▼
ClassTimetable
        │
        ├─ TimetableRenderer.RenderPng / RenderPngBytes / RenderPngToTemp（界面预览与图片导出）
        └─ TimetableRenderer.RenderPdf（高分辨率 PNG 嵌入 A4，打印）
```

- 窗口、PNG、PDF 共用同一个 `ClassTimetable`，不允许各写一套版面。
- 界面中的课表是 SkiaSharp 渲染出的位图（2× 渲染），所以屏幕所见与导出、打印完全一致。
- 没有 Excel 导出：课程表是给老师和学生看的固定版式，改 Excel 反而会破坏行序与合并关系。

## 总表识别

`MasterScheduleImporter` 只接受 `.xlsx`（`.xls` 提示另存）。依次在每张工作表的前 15 行寻找：

1. 至少 5 个星期日表头（`星期一` … `星期五`，兼容 `周一`）。
2. 前 5 列里能识别出班级行的列（`九（6）班`、`九6班`、`6班` 等）。
3. 表头下方 4 行内、每天分组里至少 6 个 `1–7` 节数字。

满足条件的候选用「班级数 × 10 + 表头距离」评分，取最高者。真实总表 `2-课程表 ` 名称末尾带空格，`ScheduleSheet` 展示时会 Trim。

每天固定 10 列：7 节课 + 课后服务1 + 课后服务2 + 晚修。节次列由表头数字定位，找不到时退回「起始列 + 节次 - 1」。

**合并单元格必须解析**：纵向合并的课服内容（如 `J5:J24 = 培优辅差`、`S5:S24 = 阳光体育`）只有左上角有值，`GetMergedText` 会先取 `MergedRange().FirstCell()` 再读。这是真实总表能正确提取 20 个班级的前提。

## 辅助表

| 信息 | 识别方式 | 缺失时 |
| :--- | :--- | :--- |
| 班主任 | 同一工作簿中含「班级 + 班主任」表头的分工表 | 警告，副标题不显示班主任 |
| 午学 | 表头含「班级」+ 5 个星期（工作表名含「午学」或表头含 `12:00`） | 警告，午学行留空 |
| 课服 / 晚修教师 | 班级行上方 3 行内同时有「课后服务1 / 课后服务2 / 晚修」的子表头 | 警告，课服使用课程表内的内容 |
| 早读 | 含「早读」且含「语文 / 英语」且长度 > 20 的备注单元 | 警告，早读行省略 |

早读解析支持「二、四语文，三、五英语」与「一、三、五英语」两种写法；出现「升旗」时周一显示 `升旗`，若同时说明「不升旗改英语早读」则显示 `英语/升旗`。

## 课程表行序（由作息模板驱动）

下表是九年级内置预设（= 历史固定行序快照）；七 / 八年级预设在其第 3 节后插入「朗读」静态合并行（10:50—11:00 / 10:50—11:10），第 4 节时间顺延（占位值，可在编辑器修改）。自定义模板在窗口编辑器中管理，存于 `%APPDATA%\TeachCraft\ClassBlock\templates`，`settings.json` 记录每个年级上次使用的模板；模板行通过 Slot（第 N 节 / 早读 / 午学 / 课服1/2 / 晚修 / 静态）绑定总表数据，显示开关只过滤绑定行，静态行与结构行始终保留。

| 行 | 时间 | 内容 |
| :--- | :--- | :--- |
| 早读 | 7:20—7:50 | 语文 / 英语 / 英语/升旗 |
| 1–4 | 8:00—11:30 | 学科，按需附任课教师 |
| 大课间 | 9:30—10:00 | 合并星期列，浅灰底 |
| 午餐 | 11:30—12:00 | 整行合并，红字 |
| 午学 | 12:00—12:30 | 教师姓名，自动补「老师」 |
| 5–7 | 14:20—16:40 | 学科 |
| 课服1 / 课服2 | 16:50—17:50 | 五天内容一致才合并 |
| 晚餐 | 17:50—18:50 | 整行合并，红字 |
| 新闻联播 | 19:00—19:20 | 合并星期列 |
| 晚修 | 19:20—20:20 / 20:30—21:30 | 高行，两段时间竖排，教师姓名 |

- 主课默认只显示学科；开启「显示任课教师」后学科加粗、教师以第二行小字显示。
- 午学、晚修始终显示教师，`FormatTeacher` 只在 2–4 个汉字的人名后补「老师」；「详见晚修附件3」这类说明原样保留。
- 课服教师优先取 `5-课后服务` 表的全名，其次用课程表单元格里的简称（如「惠兰」）。
- 表尾附早读规则说明（`早读：周一 英语/升旗 · 周二、周四 语文 · 周三、周五 英语`）。

## 版式与渲染

- 逻辑画布 1000px 宽：页边距 36，时间列 150，节次列 92，其余五等分为星期列。
- 标题 33px 加粗居中；副标题 13.5px 灰字（学期 · 月份 · 班主任）。
- 外框 2.6px 黑线，内部 1px；学科 20px 加粗，教师 13.5px，时间 13.5px 灰字。
- 午餐 / 晚餐 `#D0342C` 红字；大课间 `#F4F3EF` 浅灰。
- 晚修行高 118px，时间列内部再画一条横线分隔两段时间；节次「晚修」与五天内容纵向居中。
- 打印 PDF 用 3× PNG 嵌入 A4 竖版（QuestPDF `FitArea`），单份约 430KB，避免字体内嵌膨胀。

## 窗口

- 1440×920，三栏：左侧总表与班级列表（288）、中间课程表（自适应）、右侧设置（330）。
- 顶栏：导入总表、打印、导出图片；状态栏提示「LOCAL ONLY · 总表不上传」。
- 导入后自动选中第一个班级并生成；搜索支持班级名、`九6` 这样的 Key、班主任姓名。
- 右侧可改标题、是否显示任课教师、早读、午学、课后服务、新闻联播与晚修；改动立即重排。
- 显示「识别结果」：年级、学期、月份、工作表名、班级数；识别不全时左侧出现橙色警告块。
- 导出 / 打印前用当前设置重新组装文档，不依赖屏幕上的旧图。

## 调试入口

```powershell
TeachCraft.exe --classblock-shot <png>                                  # 空窗口
TeachCraft.exe --classblock-shot <png> <总表.xlsx>                      # 导入并选第一个班

```

## 边界

- 只支持 `.xlsx`；加密工作簿无法读取。
- 总表必须是「一表多班」结构；单班课表、图片课表、CSV 不识别。
- 只取第一张满足条件的课程表；同簿多张课程表时不合并。
- 作息由模板驱动：学校改作息只需在界面复制内置模板修改，不需要改代码；新增模板行类型或 Slot 槽位才需要改 Core 并升 Minor。
- PDF 是位图，不可检索文字；不含校历、调课、值日等额外信息。
