# 08 · 待办与后续

## 已知边界（非缺陷）

- Word→PDF 不渲染 DOCX 内嵌图片、页眉页脚、分栏、浮动对象。
- PDF→Word 文字模式丢失复杂版式；需要版式时用「保留版面」。
- PNG 压缩不降画质，体积收益来自缩小边长。
- 加密 PDF 不做破解，提示用户先解除密码。
- 归位：复杂多行表头只识别单行；加密 xlsx 无法读取；打印 PDF 为位图；暂无拖拽、撤销/重做、多班级切换。
- 安装包未做 Authenticode，macOS 为 ad-hoc 签名，未做公证（首次打开可能需右键「打开」）。

## 候选改进

1. **PDF 转图片打包 zip**：现在输出文件夹；若要一键分享，可在完成后自动打 zip。
2. **文件选择器 E2E**：用 UI 自动化覆盖原生对话框，补齐 `--selftest` 未覆盖的部分。
3. **Word→PDF 图片**：解析 `w:drawing` 的 `a:blip` 关系并嵌入图片（PDF→Word 版面模式已能反向嵌入，可复用思路）。
4. **PDF 转 Word 版面模式压缩**：当前每页 PNG @150 DPI，DOCX 偏大，可改 JPEG 或 WebP。
5. **linux-arm 支持**：需替换 QuestPDF 或对这两个工具做「不可用」降级；在此之前矩阵保持 7 RID。
6. **偏好设置 / 处理记录**：记住上次输出目录、水印文字、DPI。
7. **Windows 代码签名 / macOS 公证**：需要证书与 Apple 开发者账号。
8. **归位拖拽排座 / 撤销**：把学生从名单拖到座位，或座位之间互换；加撤销/重做。
9. **归位多班级**：保存多个班级的名单与座位配置，一键切换；可复用现有 config xlsx。
10. **归位直接打印**：接入系统原生打印对话框，而不只是打开 PDF。

## 版本节奏建议

- 新增小工具或新平台 → Minor（当前基线 1.1.0，下一档 1.2.0）。
- 只修 UI / 文案 / 兼容性 → Patch（1.1.x）。
- 工具 ID 或输出结构变化 → Major（2.0.0）。
- 版本号只改 `Directory.Build.props`，不要改工作流。
