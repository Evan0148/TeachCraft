# 01 · 项目概览

## 背景与目标

用户希望把「分晓 · GradeStrip」（智学网成绩条生成器）扩展成一只教师工具箱：保留分晓的设计语言与本地优先原则，加入常用的图片、PDF、格式转换工具，统一命名为 **知微 · TeachCraft**。

- 视觉参考与代码来源：`D:\Documents\Grade-Organizer`（正式名「分晓 · GradeStrip」）。
- 先交付 HTML 视觉稿并获得用户确认，再落成 Avalonia 桌面应用。
- 关键要求：分晓必须作为工具箱的一部分被「写进去」，而不是外链或快捷方式。

## 范围

**已交付**
- 工具壳：侧栏、案头常备（分晓）、图片处理、格式工厂、搜索、状态栏、抽屉面板。
- 10 件工具：图片格式转换、尺寸调整、压缩、文字水印；PDF 转 Word、Word 转 PDF、图片合成 PDF、PDF 转图片、PDF 合并、PDF 拆分。
- 分晓：项目引用 + 同进程打开真实主窗口，详情抽屉展示真实截图。
- Windows 安装包、macOS DMG、7 个 RID × 2 部署模式的 CI 发布。

**不做**
- 云端处理、账号、遥测、上传。
- 分晓内部的成绩算法改写（保持上游实现）。
- Linux 32 位 ARM（QuestPDF 无原生库）。

## 原则

1. 老师打开就能用：不装 .NET、不配环境、不联网。
2. 视觉与分晓同宗：纸色、墨色、陶土色、衬线标题、细边白卡。
3. 出错说人话：中文、可操作、不暴露堆栈。
4. 输出不覆盖输入；多文件顺序由用户决定。
