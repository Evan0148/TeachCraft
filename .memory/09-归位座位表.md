# 09 · 归位 · SeatGrid

## 目标

在「知微」工具箱里新增一只座位表应用：老师导入一份普通名单（xlsx / xls / csv），软件自动识别姓名、性别以及身高、视力等座位信息，按参考图的设置排座、预览、打印，并导出 Excel 与 PNG。

## 数据管线

```
RosterImporter → SeatingEngine → SeatChartComposer → SeatChartRenderer (PNG / PDF)
                                              ├→ SeatChartExcelExporter
                                              └→ SeatGridConfigIO
```

界面、PNG、PDF、Excel 共用同一个 `SeatChartDocument`，避免「预览与打印不是同一张表」。

## 名单识别

- 读取：`ExcelDataReader` 统一处理 xlsx / xls / csv；xls 通过 `CodePagesEncodingProvider` 兼容 GBK。
- 表头：扫描前 20 行，按「姓名 / 性别 / 学号 / 身高 / 视力 / 成绩 / 小组 / 备注」同义词打分，取匹配最多的一行。
- 无表头：按内容识别姓名列（中文 2–6 字或拉丁姓名）与性别列（男/女、M/F、1/0）。
- 容错：跳过空姓名、合计、平均、表头行；处理「张三(男)」、姓名后追加性别、身高 1.75（米）→ 175（厘米）、视力 5.0/4.8 → 取较差值。
- 结果附带 warnings（无性别列、重名、跳过行），导入后显示在状态栏。

## 座位模型

- 物理坐标 `SeatPosition(Group, Row, Column)`；`Row = 0` 永远是靠近讲台的第一排。
- 教师视角：讲台在下、第一排靠下；学生视角：整体旋转 180°，讲台在上、第一排靠上。视角只影响展示，不改变座位。
- 自动排座填充顺序：先填第一排，再从左到右跨组，然后逐排向后；这样「按身高 / 按视力」的前排优先才成立。
- 排座方式（1.13.0 起 6 种）：名单顺序、男女交替（异性同桌）、同性同桌（`ArrangeMode.GenderPair`，按「男男 女女」两两成对填充，性别未知排末尾，一侧用尽另一侧连排，落单时末尾允许混合对）、随机、按身高、按视力。枚举顺序 = 下拉顺序，`AutoArrange` 的 Clamp 上限随枚举同步。
- 自动排座弹窗：点「自动排座」先弹「同桌之间按哪种性别方式安排？」（`SeatGridWindow.ShowArrangeGenderDialogAsync`），异性同桌 → 男女交替、同性同桌 → 同性同桌，选中后同步下拉框再排座；当前方式为名单顺序/随机/按身高/按视力时弹窗补「按当前方式「…」排座」直达，取消则不动座位。弹窗样式与 `ConfirmDialog` 同一套纸墨色板（#FAF9F5/#141413/#E7E3D8/#C6613F）。
- 手动：点击座位选中 → 左侧选学生 →「放入所选学生」；已坐学生会被移动，目标座位原学生自动变为未排；可「清空座位」。
- 拖拽：按住有人卡片拖到另一座位——目标有人则对调、空位则移动（6px 阈值内视为点击）。座位是 Button，会吃掉指针事件，拖拽统一在窗口层用 `AddHandler(..., RoutingStrategies.Tunnel, handledEventsToo: true)` 接管（1.3.x 修复）。
- 行列调整：设置面板「调整行列」卡可整班平移（左右上下，边缘绕回，方向按当前视角换算）；行首排号把手拖动整排对调、列尾 ⠿ 把手拖动整列对调（可跨组），窗口层同一状态机按 Tag 分流 Seat/Row/Column 三种模式。
- 重复占座不允许；学生人数超过座位时，多余学生保持未排。

## 设置（对应参考图）

- 视角模式：教师 / 学生。
- 小组数量 1–8、每组排数 1–10、每组人数（列）1–4。
- 格子大小 50%–200%（基准 80px，默认 85% = 68px，保证 1440 宽窗口完整显示 4 组）。
- 座位表标题 + 标题加粗；班主任 / 人数（自动）/ 班长 → 信息行。
- 配色：座位背景、空位背景、姓名颜色、边框颜色、讲台底色、讲台文字、组标题、排标题、女生标记。
- 讲台与座位距离 0–100px；名字字体大小 10–36px。
- 名字加粗、隐藏空座位、标记女生、两字姓名自动加空格、显示组排提示。
- 座位表样式重置。
- Excel 配置导出 / 导入：`座位设置`（键值）+ `名单`（含组/排/列）两张表，A1 标记 `SeatGrid Config v1`。

## 导出

- **预览 / PNG**：SkiaSharp 渲染，默认 2x；图片与打印使用同一份 composer 结果。
- **PDF**：先渲染约 3200px 长边的高分辨率 PNG，再用 QuestPDF 放入 A4 横向/纵向，避免 SkiaSharp PDF 内嵌整套中文字体（曾达 23MB；现在约 0.4MB）。
- **Excel**：ClosedXML 生成带颜色、边框、合并标题的「座位表」+「名单」两张表；性别、学号、身高、视力、成绩、备注与座位位置全部保留。
- **配置**：`SeatGridConfigIO` 导出/导入设置、名单与座位；导入时校验布局范围与重复座位。
- **打印**：生成临时 PDF 并用系统默认阅读器打开，由老师确认后打印。
- **保护**：任何导出路径与已导入的名单路径相同都会被拒绝，避免覆盖源文件。

- 预览窗口实测：打开后作为 SeatGrid 的模态子窗口显示，关闭后状态更新；学生视角切换不崩溃。
- 演示截图：窗口 1440×920，4 组完整可见；名单、设置面板与状态栏布局正常。

## 已知边界

- 复杂合并表头只识别单行表头；多行表头可能需用户先整理。
- 加密 xlsx 无法读取，会给出中文错误。
- PDF 为高分辨率位图，文字不可选中；需要可编辑文本请用「导出 Excel」。
- 暂不支持撤销/重做、多班级切换。
- 打印依赖系统默认 PDF 阅读器；未集成系统原生打印对话框。
