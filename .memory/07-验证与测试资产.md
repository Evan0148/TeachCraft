## UI 走查

应用内置多个命令行模式：

```powershell
TeachCraft.exe --shot <png>                       # 主界面
TeachCraft.exe --shot <png> --panel <tool-id>     # 指定工具抽屉
TeachCraft.exe --shot <png> --panel project       # 分晓详情抽屉
TeachCraft.exe --gradestrip-shot <png>            # 直接截分晓窗口
TeachCraft.exe --seatgrid-shot <png>              # 归位窗口（演示名单 + 自动排座）
TeachCraft.exe --seatgrid-shot <png> empty        # 归位空名单状态，用于检查空态与网格
TeachCraft.exe --seatgrid-demo                    # 归位窗口常驻，供 UI 自动化交互
TeachCraft.exe --classblock-shot <png> [总表.xlsx] [班级Key]  # 时序窗口；可指定总表与班级
TeachCraft.exe --selftest <tool-id> <in> <out> <png>  # 跳过对话框跑完整 UI 流程
```

- 已完成 `image-convert`、`image-compress`、`pdf-merge`、`pdf-images` 的 `--selftest` 全链路（含结果文案与状态栏）。
- `--search <text>` 可验证搜索过滤与空状态。
